# mote

한국어 | [English](README.en.md)

선택한 글자에 색을 입힐 수 있는 초경량 Windows 메모장입니다.

Windows 메모장처럼 단순하게 쓰면서, 강조하고 싶은 부분에는 글자색과 굵게·기울임꼴·밑줄을 바로 적용할 수 있습니다. 설치 없이 `mote.exe` 하나로 실행됩니다.

## 주요 기능

- **글자색**: 선택한 글자에 8가지 기본 색이나 사용자 지정 색을 적용합니다. 자주 쓰는 색 세 개는 Ctrl+F1/F2/F3으로 바로 적용할 수 있습니다.
- **기본 서식**: 굵게, 기울임꼴, 밑줄
- **파일**
  - 서식 있는 문서(.rtf)는 글자색과 서식을 그대로 저장합니다.
  - 텍스트 문서(.txt)는 원래 인코딩과 줄바꿈 그대로 저장합니다.
- **찾기/바꾸기**: 입력하는 대로 바로 찾고 일치 개수를 보여 줍니다. 대소문자는 구분하지 않습니다.
- **안전한 저장**
  - 저장하지 않은 변경이 있으면 닫기 전에 묻습니다.
  - 임시 파일에 먼저 쓴 뒤 교체하므로 저장 도중 문제가 생겨도 원본이 손상되지 않습니다.
- **편의 기능**
  - 최근 파일 목록
  - 파일 끌어다 놓기로 열기
  - "연결 프로그램" 목록에 등록 (도움말 메뉴)
  - 새 창(별도 프로세스)
  - 마지막 창 위치와 크기 기억
  - 툴바 접기
- **화면**
  - Windows 설정에 따라 라이트/다크 테마로 바뀝니다.
  - 모니터 배율(DPI)이 달라도 선명하게 보입니다.
  - Windows 표시 언어에 따라 한국어/영어로 보입니다.

맞춤법 검사, 자동 교정, 클라우드, 계정, 광고, 텔레메트리는 없습니다.

## 요구 사항

- Windows 10 1809 이상 (Windows 11 권장)
- 별도 런타임 설치 필요 없음

## 사용법

[Releases](https://github.com/oodhmo/mote-notepad/releases)에서 `mote.exe`를 내려받아 원하는 폴더에 두고 실행합니다.

설정(최근 파일, 창 위치, 색 단축키 등)은 레지스트리 `HKCU\Software\mote`에 저장됩니다. 지우려면 먼저 **도움말 > 연결 프로그램에서 mote 제거**로 등록을 없앤 뒤 이 키를 삭제하면 됩니다.

### 단축키

앱에서 **F1**을 누르거나 **도움말 > 단축키 및 기능**에서도 볼 수 있습니다.

| 분류 | 단축키 | 동작 |
|---|---|---|
| 파일 | Ctrl+N | 새로 만들기 |
| | Ctrl+Shift+N | 새 창 |
| | Ctrl+O | 열기 |
| | Ctrl+S | 저장 |
| | Ctrl+Shift+S | 다른 이름으로 저장 |
| 편집 | Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| | Ctrl+X / C / V | 잘라내기 / 복사 / 붙여넣기 |
| | Ctrl+A | 모두 선택 |
| 서식과 글자색 | Ctrl+B / I / U | 굵게 / 기울임꼴 / 밑줄 |
| | Ctrl+F1 / F2 / F3 | 단축키 색 적용 (기본: 빨강 / 파랑 / 초록) |
| 찾기와 바꾸기 | Ctrl+F / Ctrl+H | 찾기 / 바꾸기 |
| | F3 / Shift+F3 | 다음 찾기 / 이전 찾기 |
| | Esc | 찾기 바 닫기 |
| 보기와 도움말 | Ctrl+\ | 툴바 숨기기 / 표시 |
| | F1 | 단축키 및 기능 |

Ctrl+F1~F3에 쓸 색은 툴바의 글자색 메뉴에서 색을 **우클릭**해 바꿀 수 있습니다. 지정된 색 아래에는 F1/F2/F3이 표시됩니다. 사용자 지정 색으로 고른 색은 메뉴의 **최근 사용한 색** 줄(최대 8개)에 나타나고, 이 색들도 같은 방법으로 단축키에 지정할 수 있습니다.

### "연결 프로그램"으로 열기

mote는 설치 과정이 없으므로 처음 한 번 등록해 두면 편합니다.

1. 처음 실행할 때 등록할지 한 번 묻습니다. 여기서 **등록**을 누르거나, 나중에 **도움말 > 연결 프로그램에 mote 등록...**을 누릅니다.
   - **나중에**를 누르면 다시 묻지 않습니다.
   - 관리자 권한은 필요 없습니다.
   - 현재 사용자 계정에만 등록됩니다.
2. 이제 `.txt`/`.rtf` 파일을 우클릭하면 **연결 프로그램** 목록에 mote가 바로 나타납니다. Windows **설정 > 앱 > 기본 앱**에도 mote가 나타납니다.
3. 항상 mote로 열려면 둘 중 하나를 고릅니다. Windows 정책상 앱이 스스로 기본 앱이 될 수는 없어서 직접 골라야 합니다.
   - 등록 직후 나오는 **설정 열기**에서 mote를 고릅니다.
   - 파일을 우클릭해 **연결 프로그램 > mote > 항상**을 누릅니다.

mote.exe를 다른 폴더로 옮겨도 다음에 실행할 때 등록된 경로가 자동으로 고쳐집니다. 등록을 없애려면 **도움말 > 연결 프로그램에서 mote 제거**를 누릅니다.

등록하지 않고 쓰려면 파일을 우클릭해 **연결 프로그램 > 다른 앱 선택 > PC에서 앱 선택**으로 `mote.exe`를 고르면 됩니다. 파일을 mote 창에 끌어다 놓아도 열립니다.

## 파일 형식과 인코딩

- **.rtf**: 글자색, 굵게, 기울임꼴, 밑줄을 저장합니다. 테마 기본색으로 쓴 글자는 "자동 색"으로 저장되어 다른 테마나 다른 앱에서도 자연스럽게 보입니다.
- **.txt**: 서식 없이 글자만 저장합니다.
  - **읽기**: UTF-8, BOM 있는 UTF-8, UTF-16(LE/BE), 시스템 언어의 기존 코드 페이지(한국어는 CP949)를 자동으로 알아봅니다.
  - **저장**: 연 파일의 인코딩과 줄바꿈(CRLF/LF/CR) 그대로 저장합니다. 새 문서는 BOM 없는 UTF-8과 CRLF로 저장합니다.
  - **CP949로 표현할 수 없는 글자**: 이모지처럼 CP949 문서에 담을 수 없는 글자가 있으면, 저장하기 전에 UTF-8로 저장할지 묻습니다.
  - **줄바꿈이 섞인 파일**: 첫 번째 줄바꿈 종류로 통일되어 저장됩니다. Windows 메모장과 같은 동작입니다.
- 열 수 있는 파일 크기는 최대 512MB입니다.

## 빌드

필요한 도구는 다음과 같습니다.
- Visual Studio 2022 (또는 Build Tools)의 "C++를 사용한 데스크톱 개발"
- CMake 3.21 이상

```powershell
cmake --preset vs2022
cmake --build --preset release
```

결과물은 `build\Release\mote.exe`입니다. CRT를 정적으로 링크하므로 다른 PC에서도 단독으로 실행됩니다.

## 버전과 릴리스

버전은 `MAJOR.MINOR.PATCH` 형식을 따릅니다.

| 바뀐 내용 | 올리는 자리 | 예 |
|---|---|---|
| 버그 수정만 (`Fix:`) | PATCH | 1.0.0 → 1.0.1 |
| 기능 추가 (`Feat:`) | MINOR (PATCH는 0으로) | 1.0.1 → 1.1.0 |
| 이전 버전과 호환되지 않는 변경 (설정·저장 형식 등) | MAJOR | 1.1.0 → 2.0.0 |

문서(`Docs:`)나 정리(`Chore:`)만 바뀐 경우에는 릴리스하지 않습니다.

정식 출시 전에 미리 써 보게 할 때는 베타 버전 `x.y.z-beta.N`을 씁니다.
- 피드백을 받아 고칠 때마다 N을 올립니다.
- 충분히 써 본 뒤 `-beta.N`을 떼고 정식 버전으로 냅니다.
- exe의 숫자 버전에는 글자를 넣을 수 없습니다. 그래서 `version.h`의 문자열에만 `-beta.N`을 붙입니다.
- GitHub에는 사전 릴리스(Pre-release)로 올립니다. 아래 4단계에서 `--prerelease`를 붙이면 되고, 그러면 "Latest"로 표시되지 않습니다.

릴리스 순서는 다음과 같습니다.
1. `resources/version.h`의 숫자와 문자열을 올리고 `Chore: 버전 x.y.z`로 커밋합니다. 버전은 이 파일에서만 바꿉니다.
2. Release로 빌드하고 **도움말 > 정보**에서 버전을 확인합니다.
3. 태그를 붙여 푸시합니다.
   ```powershell
   git tag vx.y.z
   git push origin main --tags
   ```
4. GitHub 릴리스를 만들고 `mote.exe`를 올립니다. 노트에는 지난 태그 이후의 기능 추가와 수정 내용을 한국어와 영어로 함께 적습니다.
   ```powershell
   gh release create vx.y.z build/Release/mote.exe --title "mote x.y.z" --notes "..."
   ```
